## Overview

A personal portfolio for Mastaan Randhawa, a software developer and Computer Science student at Simon Fraser University. It brings together his work across web development, system programming, and software engineering in one polished, interactive site.

## Challenge

A developer portfolio has to stand out to recruiters in seconds while still feeling personal. It needed to showcase a range of projects — from low-level C/C++ systems to interactive web builds — and demonstrate front-end craft, not just describe it.

## Solution

We built a fast React site with a memorable, physics-powered skills section where visitors can grab and toss interactive skill pills. Curated project cards, a technical-skills toolkit grouped by discipline, an about section, contact form, and downloadable resume round out a portfolio that both reads well and shows the developer's front-end ability first-hand.
